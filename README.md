# Food Delivery Operations & Delivery Time Analysis

## Project Overview
This project analyzes food delivery data using Microsoft Excel. It focuses on delivery time, traffic, weather, city types, and vehicle conditions.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Dashboard

## Dataset
- Total Records: 45,593
- The dataset contains food delivery details and delivery time information.

## Key Findings
- Average Delivery Time: 26.29 minutes
- Maximum Delivery Time: 54 minutes
- Minimum Delivery Time: 10 minutes
- High traffic increases delivery time.
- Semi-Urban areas have a higher average delivery time.
